## 0. 判定依据：原始技能串与「最后学会的四个技能」

### 0.1 图鉴 `技能=` 字段的编码格式

biligame 精灵页的 `技能=` 是一串以 `;` 分隔的条目，单条形如：

```
技能ID-学习等级
技能ID-学习等级-标记
技能ID-学习等级-分类-标记
```

- 第三段（可选）在新精灵上是**分类名**：`先手` / `防御` / `强化` / `制敌` / `追加` / `第五`。
  例：克律莎（图鉴 4944）的 `38530-21-先手-1;29451-49-防御-1;29452-57-强化-1;38531-61-制敌-1;38532-76-第五`。
- 在 3142 / 3242 这类早期精灵上，第三段是**纯数字 `1`**（旧格式的附加标记），第四段不存在；同一只精灵里只有部分技能带 `-1`。
- `追加` = 追加技能；SeerAPI 侧对应 `is_special = true`（王·雷伊 30122、王·盖亚 30185 实测均为 `true`）。
- `第五` = 第五技能；SeerAPI 侧对应 `is_fifth = true`（王·雷伊 19734 = 等级 95；王·盖亚 30158 = 等级 76）。
- 本文所有字段（威力 / 次数 / 先制 / 命中率 / 暴击概率）都以图鉴 `技能:` 页的 `{{技能|...}}` 原文为准，用 SeerAPI 的 `power / max_pp / priority / accuracy / crit_rate` 逐条核对。
