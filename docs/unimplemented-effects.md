口径说明：

- **"全属性"= 六项**：攻击 / 防御 / 特攻 / 特防 / 速度 / 命中，正好是 `Pet.STAT_STAGE_FIELDS`。

- **"每处于一种能力提升状态"按项数算，不按等级数**：24970 的 10% 乘的是"有几项能力 >
  0 级"（2 项 = ×1.2），这与 30157 的"能力下降**等级总和**"（-3 与 -1 合起来是 4 级）不是
  一回事。25184 的"高于最大体力的 1/2"是严格大于，恰好一半按 +1。
- **"不出现微弱"不覆盖免疫**：只把 (0,1) 的克制倍率抬回 1；0（无效）保持 0。

## 二、用现有 API 组合的"模拟实现"（语义近似，待核心提供原生入口）

### 1. 极度冲刺（30156）/ 万鸣齐闪（24970）：反转自身能力下降

- 原文：**反转自身能力下降状态**
- 实现（`reverseNegativeStages`）：遍历 `Pet.STAT_STAGE_FIELDS`，对每个负等级发一条
  "增量 = -2×当前等级"的 `room:changeStatStages`（-n → +n）；正等级与 0 不动；没有负等级
  时不产生任何写入。数值结果与反转一致。
- 近似的边界：`core/events/stat_stage.lua` 已经定义了 `operation = "reverse"` 的数据契约
  和 `Before/AfterStatStagesReverse` 时机，但注释明确"本次不提供 Room 反转函数"。
  组合写法走的是普通 `change` 操作、发 `operation = "change"` 的通知，也没有专用的反转
  前后时机；`docs` 与技能 desc 都按"用能力变化组合近似"注明。
- 需要核心补：**`BattleRoom:reverseStatStages(target, source, reason)`**，实现已定义好的
  `reverse` 操作并复用 `Before/AfterStatStagesReverse`；补齐后应把这两条效果迁移过去。
- 结算时机：两条都挂在 `SkillUsed`（命中判定之后、伤害链之前）。30156 是攻击技，
  所以反转出来的正等级会参与本次伤害计算；原文没写先后，这里按"使用技能时先反转"处理。

### 2. 王·圣勇战意（30158）：吸取对手能力提升状态

- 原文：**吸取对手能力提升状态，吸取成功则吸取对手300点体力**
- 实现（`wang_shengyong_steal_positive`，`AfterAttack`）：读对手所有正等级 →
  `room:clearPositiveStatStages`（清正等级走 `clear_positive`，不冒充弱化）→
  `room:changeStatStages` 以同额加给自身（上限仍受 ±6 约束）。
- 边界：只实现了"状态转移"这半句；"吸取 300 体力"需要规则层固定伤害/吸血入口（见第六节）。
- 时机说明：放在 `AfterAttack`（命中并结算完伤害之后），符合"命中后吸取"的直觉；
  原文没有写明先后。

## 四、完全未实现（原文 → 为什么不行 → 核心要补什么）

### 1. 寰宇雷神断（19733，物理/电/150/PP5/95%）

- 原文：**50%使对手麻痹，自身每处于一种能力提升状态则概率提高8%**
- 为什么表达不了：核心**没有异常状态系统**。麻痹不是能力等级也不是伤害数值，
  它需要"精灵身上的状态标记 + 出手/命中环节查询 + 回合递减"。按概率触发本身没问题
  （`ctx.logic.rng` 可用），缺的是状态本身。
- 需要核心补：异常/控制状态系统（登记状态类型、挂到 pet、影响出手与命中、按回合递减
  与清除），外加"免疫异常状态"的查询入口。

### 2. 万鸣齐闪（24970）后半段

- 原文：**直接造成260点电系伤害，自身每处于一种能力提升状态则造成的伤害提高10%**
- 为什么表达不了："直接造成 260 点某属性伤害"是技能结算里的固定伤害，不属于攻击/伤害链。
  现有唯一改血口 `logic:changeHp(target, -260, reason)` 是**底层写血**：绕过暴击、克制、
  伤害时机，也没有任何"伤害来源/属性/防止"的语义。用它凑出来的是假伤害，按用户要求不做。
  因此那 10% 的增伤虽然数学干净（`wang_wanming_stage_boost`），也**没有载体**：
  24970 是属性技，永远不进伤害链，所以这个效果只定义 + 单测，不挂到技能上。
- 需要核心补：**规则层固定伤害入口** `logic:dealFixedDamage(target, num, element, reason)`
  （走伤害时机、可被防止/免疫、可被增伤修正）；有了它再把 260 与 ×10% 接起来。

### 3. 王·万霆朝宗（19734）的第二、四段（第三段已实现）

- 原文：**消除对手回合类效果，消除成功则下回合自身造成的攻击伤害额外提升100%；
  未击败对手则自身全属性+1；未击败对手则下回合自身所有技能先制+2**
- 已实现的"未击败对手则全属性+1"用 `AfterAttack` + `logic:isFainted(target)` 判定，
  干净可做（见第一节）。其余两段：
  1. "回合类效果"是一整类在场效果，核心**没有回合类效果注册表**，也没有"按分类清除
     对手效果"的接口；"消除**成功**"因此也无从判断（连带第 2 段的下回合 +100% 悬空）。
  2. "下回合自身所有技能先制+2"：技能先制度是静态字段（`Skill.priority`），而且出手顺序
     在 `GameLogic:doRound` 里**先排序、后触发 `DecidePriority`**，效果时机改不动已定的顺序。
- 需要核心补：回合类效果注册表与清除接口；排序前的先制修正钩子（把 `DecidePriority` 拆成
  "收集修正 → 排序 → 公布"）。

### 4. 不败之境（25184）后两段

- 原文：**4回合内每回合使用技能吸取对手最大体力的1/3；下2回合令自身所有技能先制+2**
- 为什么表达不了：前者需要回合类效果系统 + 规则层吸血入口（同第 2 条的固定伤害问题）；
  后者同第 3 条第 2 点（静态先制度 + 排序在效果时机之前）。

### 5. 战霸天下（25183）

- 原文：**4回合内免疫并反弹所有受到的异常状态；5回合内免疫能力下降状态；
  将下次受到的伤害200%反馈给对手**
- 三段都表达不了：异常状态系统、回合类效果系统 + "免疫能力下降"查询钩子、
  伤害反伤入口（`AfterDamageCalculate` 只能改本次伤害数值，没有"对另一方造成伤害"的
  规则层入口，用 `changeHp` 反写又是底层写血）。技能 `effects = {}`。

### 金翼剑轮（19731）——"免疫下 1 次受到的攻击"的模拟边界

- 计数在 pet 字段上（`wang_immune_attacks`），不参与"效果分类"：**无法被"消除对手回合类
  效果""驱散"之类的机制处理**，也不会随换人/下场统一清理（当前战斗模型没有换人），
  效果之间也无法叠加成多层护盾。
- 需要核心补：原生"免疫次数 / 护盾 / 抵挡"系统（可分类、可清除、可叠加、可过期）。

### 天威力破（30155）——"下 2 回合必致命"

- 状态挂在 pet 上（`wang_crit_guarantee` + 两个常驻 Effect），`TurnEnd` 到时清理；
  "回合"直接读 `logic.round`。"攻击"的定语（是否区分物理/特殊、是否含固定伤害）原文没有
  细化，这里按"下一次造成伤害的攻击"处理；多段攻击只翻第一击。
